# SCENTHOOD — The Fragrance Community That Thinks

A luxury fragrance community platform built as a Proof of Concept for the **L'Oréal Brandstorm 2026** competition.

## What is SCENTHOOD?

SCENTHOOD is a community-driven platform strategy for L'Oréal Luxe, launching first in Egypt. It enables fragrance enthusiasts to:

- **Vote** on the next accord directions for brands like YSL and Maison Margiela Replica
- **Contribute** reviews, fragrance memories, and cultural insights
- **Earn** a Cultural Contribution Score (CCS) and rise through tiers
- **Co-create** fragrance briefs with master perfumers

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript
- **Data**: Mock/hardcoded (no backend required)

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Path | Description |
|------|-------------|
| `/` | Landing page with hero and market stats |
| `/quiz` | 5-step Scent Profile onboarding quiz |
| `/home` | Community home feed with featured vote |
| `/vote` | Live Accord Voting |
| `/profile` | CCS Dashboard & user profile |
| `/community` | Community feed with reviews |
| `/tiers` | Tier system (Scenthooder → Scentmaker → Council) |
| `/intelligence` | Internal analytics dashboard |
| `/brands` | Pilot brands (YSL Beauté & Maison Margiela Replica) |
